QuantPilot — Quantitative Research & Trading Simulator

Problem Statement

Financial engineering students and quantitative researchers lack collaborative, low-latency backtesting and paper-trading environments with deterministic financial arithmetic, rigorous multi-user isolation, and probabilistic risk analysis.

Solution Architecture

Engineered a reactive single-page application using React 19 and Vite with TypeScript, integrating Supabase (PostgreSQL with Row Level Security) for multi-tenant isolation across 5 concurrent user workspaces. Built a deterministic financial accounting engine guaranteeing zero rounding discrepancy, integrated Recharts for candlestick and volume charts, and connected Google Gemini API for trade journal risk synthesis.

Individual Contribution

Sole architect and developer. Designed the full-stack architecture, developed the deterministic financial math ledger, implemented Supabase database schemas and RLS security policies, built real-time chart rendering, and authored documentation.

Interactive LLM Tokenization Engine & Playground

Problem Statement

Machine learning students and developers struggle to intuitively grasp how Large Language Models decompose Unicode text into subword token IDs, byte-pair merges (BPE), and high-dimensional vector embeddings across differing tokenizer architectures.

Solution Architecture

Constructed an in-browser client-side tokenization workbench running WebAssembly and Transformers.js. Executes real-time tokenizer parsing directly on the client with zero network latency, color-codes subword token boundaries, computes vocabulary entropy metrics, and simulates cosine similarity across token embeddings in a dynamic vector space.

Individual Contribution

Engineered the client-side token parsing pipeline, built the multi-tab visual exploration interface (Tokens, Embeddings, Similarity, and Analogy vector space), optimized rendering loops for real-time keystroke processing, and deployed the interactive playground.

JavaScript (ES2024) HTML5 Canvas Transformers.js WebAssembly (WASM) Hugging Face API
