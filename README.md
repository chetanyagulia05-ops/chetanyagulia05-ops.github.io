## 4. Software Engineering Projects

### Project 1: QuantPilot — Multi-User Quantitative Research & Paper-Trading Simulator
- **Problem Statement**: Financial engineering students and independent quantitative researchers frequently face steep hurdles when validating trading hypotheses: institutional backtesting tools are cost-prohibitive, lack collaborative multi-user isolation, and often suffer from floating-point arithmetic errors in simulated trade execution and P&L tracking.
- **Solution Architecture**: Architected as a modular single-page application powered by React 19, TypeScript, and Vite. Utilizes Supabase (PostgreSQL with Row Level Security) to provide deterministic multi-tenant data boundaries for up to 5 concurrent research seats. Integrates a custom financial math ledger guaranteeing zero-rounding leakage, interactive Recharts canvas candlestick visualizations with volume indicators, and a Google Gemini AI integration for contextual scenario risk evaluation and trade journal synthesis.
- **Tech Stack**: React 19, TypeScript, Vite, Tailwind CSS v4, Recharts, Lucide React, Supabase (PostgreSQL with RLS), Google Gemini 2.5 API, ESLint / Oxlint.
- **Individual Contribution**: Sole developer and architect. Authored the complete client architecture, wrote the deterministic financial math ledger (accounting for cash, margin, buying power, slippage, and realized/unrealized P&L), designed the database schema with RLS policies, implemented real-time chart rendering, and authored comprehensive repository documentation.
- **Repository & Documentation**: [https://github.com/chetanyagulia05-ops/quantpilot](https://github.com/chetanyagulia05-ops/quantpilot)

### Project 2: Interactive LLM Tokenization Engine & Pipeline Playground
- **Problem Statement**: Machine learning engineers and students struggle to build intuitive mental models of how modern Large Language Models decompose Unicode text into subword token IDs, byte-pair merges, and vector embeddings across differing tokenizer architectures (e.g. Byte-Pair Encoding in GPT-4 vs SentencePiece in LLaMA/Gemma).
- **Solution Architecture**: Built as an interactive client-side browser workbench combining Hugging Face Transformers.js and WebAssembly. Executes real-time tokenizer parsing directly in the browser with zero server latency, color-codes token boundaries with glyph/byte inspections, calculates vocabulary density metrics, and computes cosine similarity metrics across token embeddings.
- **Tech Stack**: HTML5/CSS3 (Custom Glassmorphic design tokens), Modern JavaScript (ES2024), Transformers.js, WebAssembly (WASM), Canvas API.
- **Individual Contribution**: Engineered the client-side token parsing pipeline, built the interactive multi-tab exploration interface (Tokens, Embeddings, Similarity, and Analogy vector space), optimized rendering loops for real-time keystroke processing, and deployed the interactive playground.
- **Repository & Documentation**: [https://github.com/chetanyagulia05-ops/tokenizer-playground](https://github.com/chetanyagulia05-ops/tokenizer-playground)
